# Agar_Pad_Image_Analysis

This folder contains notebooks for agar pad image analysis (segmentation, feature extraction, and downstream phenotype summaries).

## Contents (manifest)

- `Example_Analysis/`
  - `Example_Analysis_Notebook.ipynb` — Example end-to-end agar pad analysis workflow.

- `FusA_Isolates/`
  - `Agarpad_Analysis.ipynb` — Analysis notebook for FusA isolate agar pad datasets.

- `R_Protein_Isolates/`
  - `Agarpad_Analysis.ipynb` — Analysis notebook for ribosomal protein isolate agar pad datasets.

- `Translation_Isolates/`
  - `Agarpad_Analysis.ipynb` — Analysis notebook for translation-related isolate agar pad datasets.

- `environment.yml` — Conda environment specification used for the agar pad analysis notebooks.
